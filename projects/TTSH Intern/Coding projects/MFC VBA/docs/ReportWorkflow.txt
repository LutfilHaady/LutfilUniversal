HOW TO FIND OUT BACKLOG NUMBERS FOR DAILY UPDATE:
1.	Open previous day’s MFC excel
2.	Copy all names
3.	Go to present date MFC excel, select the cell below the last name, paste to combine
               
     



4.	Highlight all the names  Head to home tab at control panel  Conditional Formatting  Highlight cells rules  Duplicate values  OK
 
5.	Backlog cases are highlighted in red. Delete the pasted names after noting the backlog no.
