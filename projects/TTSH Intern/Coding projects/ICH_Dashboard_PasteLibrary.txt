  Col B  → [Referral case taken by]
  Col E  → [Referring source (TTSH/Ren Ci/External)]
  Col F  → [Referring location]
  Col G  → [Patient's name]
  Col H  → [Patient's NRIC]
  Col I  → [Referral ordered Date]
  Col J  → [Referral ordered Time]
  Col K  → [Referring Discipline]
  Col AI → [Logic Checker (Triage Recommendation)]
  Col AJ → [CRE Swab Status]
  Col AK → [MRSA Swab Status]
  Col AL → [VRE Swab Status]
  Col AM → [Decision Date]
  Col AO → [TAT (Order to Completion)]
  Col AQ → [Lapse Reason]
  Col AR → [Escalated to Clinician?]
  Col AS → [Referral Status (Accepted/Rejected/Withdrawn/Cancelled)]
  Col AT → [Receiving Ward Type]
  Col BB → [PSO Comment]
  Col BC → [Final Referral Status (Do not amend)]

PENDING DEFINITION

  && !IsBlank([Referral case taken by])

NOTE: Excel Online connector column names must match the header row
exactly (row 2 of the sheet). If a column name errors, check for
trailing spaces in the Excel header.

[DH] PENDING SCREEN — FILTERED DATA COLLECTION
================================================================
Put this on the filter bar's OnChange, or on each dropdown's OnChange.
Also call it from App.OnStart after the data source loads.

→ Formula (paste onto each dropdown's OnChange):
ClearCollect(colPendingFiltered,
  Filter(Table1,
    IsBlank([Final Referral Status (Do not amend)]),
    !IsBlank([Referral case taken by]),
    Or(DropFState.Selected.Value = "All states",
       And(DropFState.Selected.Value = "With PSO",
           [Escalated to Clinician?] = "NO"),
       And(DropFState.Selected.Value = "Awaiting SC",
           [Escalated to Clinician?] = "YES")),
    Or(DropFDisc.Selected.Value = "All disciplines",
       Upper(Trim([Referring Discipline])) =
       Upper(Trim(DropFDisc.Selected.Value))),
    Or(DropFWard.Selected.Value = "All ward types",
       Upper(Trim([Receiving Ward Type])) =
       Upper(Trim(DropFWard.Selected.Value))),
    Or(DropFAge.Selected.Value = "Any age",
       And(DropFAge.Selected.Value = "Overdue (>3 days)",
           DateDiff([Referral ordered Date], Today(), Days) >= 3),
       And(DropFAge.Selected.Value = "2-3 days",
           DateDiff([Referral ordered Date], Today(), Days) >= 2,
           DateDiff([Referral ordered Date], Today(), Days) < 3),
       And(DropFAge.Selected.Value = "<2 days",
           DateDiff([Referral ordered Date], Today(), Days) < 2))
  )
)

NOTE: Upper(Trim()) handles the ward type casing bug (Gen IR vs GEN IR).

[DL] ANALYTICS SCREEN — PIE CHART
================================================================
Power Apps has a built-in Pie chart control (Insert → Charts → Pie).
It reads from a collection, not directly from a table.

Step 1 — build the collection (put in App.OnStart or screen's OnVisible):

ClearCollect(colOutcomePie,
  {Label:"Accepted",
   Value: CountRows(Filter(Table1,
     [Final Referral Status (Do not amend)]="Accepted With Admission Details"))},
  {Label:"Rejected",
   Value: CountRows(Filter(Table1,
     [Final Referral Status (Do not amend)]="Rejected"))},
  {Label:"Cancelled",
   Value: CountRows(Filter(Table1,
     StartsWith([Final Referral Status (Do not amend)],"Cancelled")))},
  {Label:"Withdrawn",
   Value: CountRows(Filter(Table1,
     [Final Referral Status (Do not amend)]="Withdrawn"))}
)

Step 2 — Pie chart control properties:
  Items: colOutcomePie
  Series: "Value"
  Labels: "Label"
  X:150  Y:136  Width:300  Height:280
  ShowLabels: true

LIMITATION: Power Apps pie chart does not support custom slice colours.
The chart picks its own colour scheme. You cannot override it without
a premium connector. This is a known constraint — accept it.

To compensate, add a manual colour-coded legend below the chart:
4 rectangles (14×14) + labels side by side:
  ■ Accepted   ■ Rejected   ■ Cancelled   ■ Withdrawn
Use the [DA] colours for the rectangles. This gives visual clarity
even if the chart colours don't match exactly.

  ForAll(
    GroupBy(
      Filter(Table1, !IsBlank([Final Referral Status (Do not amend)])),
      "Referring Discipline",
      "Cases"
    ),
    {
      Discipline: 'Referring Discipline',
      Total: CountRows(Cases),
      Accepted: CountRows(Filter(Cases,
        [Final Referral Status (Do not amend)]="Accepted With Admission Details")),
      Rejected: CountRows(Filter(Cases,
        [Final Referral Status (Do not amend)]="Rejected")),
      Cancelled: CountRows(Filter(Cases,
        StartsWith([Final Referral Status (Do not amend)],"Cancelled"))),
      Withdrawn: CountRows(Filter(Cases,
        [Final Referral Status (Do not amend)]="Withdrawn")),
      AccPct: Round(
        CountRows(Filter(Cases,
          [Final Referral Status (Do not amend)]="Accepted With Admission Details")) /
        CountRows(Cases) * 100, 0),
      NonAccPct: Round(
        (CountRows(Cases) -
         CountRows(Filter(Cases,
           [Final Referral Status (Do not amend)]="Accepted With Admission Details"))) /
        CountRows(Cases) * 100, 0)
    }
  )
)

================================================================
[DS] COMMON ERRORS TO WATCH FOR
================================================================
1. Column name spaces — Excel Online column names with spaces need
   square brackets: [Patient's name] not 'Patient''s name'

2. TAT column is in DAYS not hours — always multiply by 24:
   [TAT (Order to Completion)] * 24 >= 72  (not >= 3)

3. Ward type casing — data has both "Gen IR" and "GEN IR".
   Always wrap in Upper(Trim()) when filtering by ward type.

4. GroupBy + ForAll for discipline stats — ForAll is not delegable
   in Excel Online. If you get a warning about delegation, the
   collection will still work but will be capped at 500 rows.
   At 646 rows you are fine. This becomes a problem if the file
   grows past 2000 rows — flag it when that happens.

5. Pie chart colours — not controllable in standard licensing.
   Do not spend time trying to match the mockup colours. Build the
   manual legend instead ([DL]).

6. Detail panel flicker — if gblSelected causes controls to
   jump, ensure recDetailPanel has the same Visible formula as
   all controls inside it: !IsBlank(gblSelected)
