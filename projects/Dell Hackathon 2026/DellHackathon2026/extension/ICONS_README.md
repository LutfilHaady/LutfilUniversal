# Extension Icons

You need to create icon files for the Chrome extension. Create the following files in the `public/icons/` directory:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels  
- `icon128.png` - 128x128 pixels

You can use any image editor or online tool to create these icons. The icons should represent the VOX Co-pilot brand (suggested: teal/blue color scheme with a simple, professional design).

For quick testing, you can use placeholder images or simple colored squares.
